# WebHL

Reconstrucción del sitio corporativo de Grupo HL (hlingenieros.com).

- `docs/Diagnóstico integral – hlingenieros.com.pdf`: diagnóstico del sitio actual (29-sep-2026).
- `docs/Nuevo Sitio Grupo HL.html`: propuesta de rediseño (Rev. 0, 06-oct-2026). Abrir en el navegador.
- `CLAUDE.md`: contexto del proyecto, decisiones pendientes y convenciones.
- `docs/guia-visual.md`: guía visual base (identidad, color, tipografía, retícula, componentes, movimiento).
- `design/tokens.css`: tokens de diseño, la única fuente de verdad de los valores.
- `design/contraste.py`: verificación de contraste WCAG de los tokens (`python design/contraste.py`).
